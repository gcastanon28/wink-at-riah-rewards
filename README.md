# Wink At Riah Rewards

Next.js loyalty app for Wink At Riah clients.

## Environment

Set these variables in local and production environments:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_APP_URL`
